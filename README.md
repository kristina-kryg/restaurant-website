# Pizza Website

A pizza landing page for an authentic Italian pizzeria: the website showcases signature pizzas, featured menu items, customer feedback, and a strong call-to-action for ordering.

## Live Demo

https://kristina-kryg.github.io/restaurant-website/

## Overview

This project is a static website built with HTML, CSS and JS. It includes:

- A hero section with a warm, restaurant-style design
- Featured pizza menu cards
- A highlighted special pizza offer
- Product and food highlight sections
- Customer testimonial area
- Downloadable menu section
- Footer with contact and social links

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local image assets
